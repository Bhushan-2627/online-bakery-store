# 🍰 Sweet Crumbs - Online Bakery Store

Sweet Crumbs is a web-based online bakery store developed as a group activity project.

## Features

- 🏠 Home page
- 🧁 Bakery product catalogue
- 🛒 Shopping cart
- 💳 Checkout and order placement
- 📊 Business Analytics Dashboard
- 📈 Sales visualizations
- 🔍 Descriptive Analysis
- 🔎 Diagnostic Analysis
- 🔮 Predictive Analysis
- 💡 Prescriptive Analysis
- 📱 Responsive design
- 📞 Contact page
- ℹ️ About page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git & GitHub

## Analytics

The dashboard uses order data stored in the browser to calculate:

- Total Sales
- Total Orders
- Customers
- Best-Selling Product
- Product Sales
- Category Sales
- Monthly Sales Trend
- Predictive Insights
- Prescriptive Recommendations
